## 이 발주의 성격 — 읽고 시작할 것

**이건 정적 HTML 목업이다. 앱 코드가 아니다.**

`AGENTS.md` 는 「모든 UI」를 Codex 대상에서 제외한다. 이 발주는 사용자가 명시적으로
뒤집은 것이고(2026-08-14), 다음 두 조건에서만 성립한다:

1. **부수효과 0** — 새 HTML 파일 하나만 만든다. 앱 코드(`public/`, `src/`, `functions/`)를
   **한 글자도 고치지 않는다.** JS 로직도 안 붙인다. 보이는 것만 만든다
2. **판단할 자리 0** — 색·크기·간격·문구를 아래에 전부 값으로 적었다.
   **적히지 않은 것은 만들지 말고 멈추고 물어라.** 「알아서 예쁘게」는 이 발주에 없다

> **왜 이렇게까지 조이나:** 2026-08-13 에 UI(인증 화면)를 넘겼다가 Critical 2건이
> 정확히 그 구간에서 나왔다. 목업은 부수효과가 없어서 그 위험이 없지만,
> **명세가 허술하면 결과물을 쓸 수 없다는 위험은 그대로다.**

## 2. 만들 화면 6개 — 한 파일에 가로로 나열

각 화면 위에 제목(`<b>`)과 한 줄 설명을 단다. 화면끼리 `gap:20px`.

### 화면 1 — `검색 0건 · 브랜드 없음` (A6)

```
‹ 뒤로   점심 항목 추가
[ 서브웨이 이탈리안BMT        ] [추가]

⚠ 식약처 DB에 없는 음식입니다. 프랜차이즈 메뉴는 대부분 등록돼 있지 않습니다.
   아래에 한 번만 넣어두면 다음부터 1탭으로 기록됩니다.

이름      [ 서브웨이 이탈리안BMT ]
칼로리 (kcal)  [ 포장지·매장 표기를 보고 ]      ← 플레이스홀더
탄 · 단 · 지 (g)  [ 모르면 비워둬도 됩니다 ]    ← 플레이스홀더

( ✓ 자주 먹는 것에 저장 )   ← 켜진 칩
[         추가          ]
```

- 경고 상자는 **주의 배경/테두리**
- 「✓ 자주 먹는 것에 저장」 칩은 **켜진 상태**로 그린다(기본 켜짐)

### 화면 2 — `그릇 단위로 양 고르기` (A5)

```

ℹ 1인분 정보가 없어 같은 분류(면 및 만두류)의 대표 중량으로 계산합니다.

얼마나 드셨나요
( 반 그릇 ) ( 한 그릇 ) ( 한 그릇 반 ) ( 두 그릇 )
             ↑ 켜짐

  623 kcal    한 그릇 ≈ 700g

[       이대로 추가       ]
```

## 3. 문구 규칙 — 그대로 복사할 것

위에 적힌 한국어 문구를 **한 글자도 바꾸지 않는다.** 특히:

- 전부 **존댓말**(`-합니다` / `-하세요`). 평서체(`-한다`)로 바꾸지 않는다
- 「1인분」과 「참고값」은 **다른 뜻이다.** 서로 바꿔 쓰지 않는다
  (1인분 = DB 에 있는 실제 값 / 참고값 = 같은 분류에서 추정한 값)
- 「추정」 배지 문구는 정확히 `추정` 두 글자
