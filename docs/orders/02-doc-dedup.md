## 문제

`coin-bot/`의 `CLAUDE.md`(134줄)와 `AGENTS.md`(121줄)가 **90줄 겹친다.**
`AGENTS.md`는 `CLAUDE.md`에서 「팀 라우팅」 섹션만 뺀 사본이고, 나머지는 완전 동일하다.

지금은 내용이 같아서 문제가 없다. **한쪽만 고치는 순간 Claude와 Codex가 다른 규칙을 따른다.**
실주문 게이트·리스크 가드 규칙이라 어긋나면 비싼 쪽이다.

`stock/`은 `AGENTS.md`가 아예 없어서 Codex가 프로젝트 규칙을 못 읽는다.

## 목표 구조

```
AGENTS.md   ← 공통 계약 (Codex가 직접 읽음)
   ↑ @AGENTS.md 임포트
CLAUDE.md   ← Claude 전용만
```

`~/Desktop/claude/meal-calendar/AGENTS.md` + `CLAUDE.md`가 **이미 이 구조다. 그걸 본으로 삼는다.**

# C. 검증 스크립트

`scripts/check-doc-split.sh` 를 만든다. **인자로 프로젝트 디렉토리를 받는다.**

```bash
./scripts/check-doc-split.sh ../coin-bot
```

## 검사 항목 (전부 통과해야 exit 0)

| # | 검사 | 실패 조건 |
|---|---|---|
| 1 | `CLAUDE.md` 에 `@AGENTS.md` 가 있다 | grep 실패 |
| 2 | **본문 중복 없음** | 두 파일의 공통 줄이 1줄이라도 있으면 실패 (아래 예외 제외) |
| 3 | **내용 유실 없음** | 원본에 있던 `## ` 헤딩이 두 파일 어디에도 없으면 실패 |
| 4 | 절대 규칙이 `AGENTS.md` 에만 | `CLAUDE.md` 에 `절대 규칙` 헤딩이 있으면 실패 |

### 2번 예외 (중복으로 세지 않는다)

- 빈 줄
- `---` 구분선
- 마크다운 표 구분행 (`|---|---|` 형태)
- 3자 미만인 줄
- **코드펜스 마커** — 줄 전체가 백틱만으로 이루어진 경우 (` ``` ` 또는 ` ```<언어명> `). 정확히 3자라 위 "3자 미만" 규칙에 안 걸리지만, 여러 코드 블록이 양쪽 파일에 있으면 펜스 줄 자체가 겹쳐서 오탐이 난다. **줄이 백틱 3개로 시작하면 예외로 친다** (그 뒤 언어명 유무 무관)

> **정정 (2026-08-13, 발주02 1차 실행에서 중단됨):** 원래 예외 목록에 코드펜스가 없어서
> `coin-bot`/`stock` 양쪽 문서에 코드 블록이 있으면 펜스 줄이 "중복"으로 잡혀 2번 검사를
> 통과할 수 없었다. Codex가 실행 전에 이 모순을 발견하고 멈췄다 — 옳은 판단이었다.
> 이 예외를 추가해 재발주한다.

> `comm -12 <(sort A) <(sort B)` 로 공통 줄을 구한 뒤 위 예외를 걸러낸다.
> **NFD 문제 주의**: 한글이 섞이므로 bash 문자열 비교가 어긋날 수 있다.
> 불안하면 이 검사만 Python(`unicodedata.normalize('NFC', s)`)으로 구현한다.

### 3번 검증 방법

원본을 미리 백업해서 비교한다. 작업 전에:

```bash
cp coin-bot/CLAUDE.md /tmp/coin-bot-CLAUDE.orig.md
```

스크립트는 `--orig <파일>` 인자를 받아 그 파일의 `## ` 헤딩이 전부 살아있는지 본다.
`--orig` 없이 호출되면 3번은 건너뛰고 그 사실을 출력한다.

## 출력

실패 항목마다 **무엇이 왜 실패했는지** 한 줄. 중복이면 **겹친 줄 예시 3개**를 보여준다.
성공하면 `OK <디렉토리>`.
