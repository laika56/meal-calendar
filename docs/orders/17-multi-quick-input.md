# 발주 17 — 한 줄에 여러 음식 (빠른 기록 다중 입력)

## 왜

한 끼에 음식이 하나뿐인 경우가 드물다. 지금은 `parseQuickFoodInput` 이 입력 하나를
**항목 하나로만** 파싱해서, 이렇게 치면 통째로 한 이름으로 본다:

```
반숙란 2개, 단백질쉐이크 1스쿱
```

여러 개를 넣으려면 `+ 추가` 를 반복해야 한다. 한 줄로 끝내게 만든다.

**기존 단일 입력 동작은 그대로 둔다.** 이 발주는 「나누는 층」을 하나 얹는 것이다.

## 만들 / 고칠 파일

## `splitQuickFoodInput(input)` — 신규

```js
export function splitQuickFoodInput(input)
// → [{ text, parsed }, ...]
//   text   = 잘라낸 원문 조각 (정규화됨)
//   parsed = 그 조각에 parseQuickFoodInput 을 돌린 결과 (기존 반환 형태 그대로)
```

### 구분자

**쉼표(`,`)와 줄바꿈만** 구분자로 본다. 그 외는 나누지 않는다.

- `+` 는 나누지 않는다 — 제품명에 들어간다 (`비타민B+C`)
- `와`/`과`/`랑` 같은 조사는 나누지 않는다 — 음식 이름에 들어간다 (`김치와 두부`)
- 공백은 나누지 않는다 — `반숙란 2개` 자체가 공백을 포함한다

| 입력 | 조각 |
|---|---|
| `'반숙란 2개, 단백질쉐이크 1스쿱'` | `['반숙란 2개', '단백질쉐이크 1스쿱']` |
| `'밥 한 공기,김치 100g'` (쉼표 뒤 공백 없음) | `['밥 한 공기', '김치 100g']` |
| `'반숙란 2개\n우유 200g'` | `['반숙란 2개', '우유 200g']` |
| `'반숙란 2개'` (구분자 없음) | `['반숙란 2개']` — **한 조각짜리 배열** |
| `'반숙란 2개,,우유 200g'` | `['반숙란 2개', '우유 200g']` — 빈 조각 버림 |
| `'반숙란 2개, , 우유 200g'` | `['반숙란 2개', '우유 200g']` — 공백뿐인 조각도 버림 |
| `'  , ,  '` | `[]` |
| `''` / `'   '` | `[]` |
| `null`, 숫자, 배열, 객체 | `TypeError` |

### 조각 정규화

각 조각에 대해 `parseQuickFoodInput` 과 **같은 정규화**를 먼저 한다:
앞뒤 공백 제거 + 내부 연속 공백 1개. `text` 에는 그 정규화된 문자열을 담는다.

### 개수 상한

**최대 10조각.** 넘으면 앞의 10개만 남긴다.
한 끼에 11가지를 한 줄로 치는 건 오타일 가능성이 높고, 조각마다 API 질의가 나간다.

### `parsed` 는 그대로 통과시킨다

각 조각에 `parseQuickFoodInput(text)` 를 돌린 결과를 **가공 없이** 담는다.
실패한 조각(`{ ok: false, reason: ... }`)도 **버리지 않고 그대로 넣는다** —
화면이 "이 조각은 못 알아들었다"고 사람에게 보여줘야 한다 (절대규칙 7).

```js
splitQuickFoodInput('반숙란 2개, 이상한거')
// → [
//     { text: '반숙란 2개', parsed: { ok: true, query: '반숙란', ... } },
//     { text: '이상한거',   parsed: { ok: false, reason: 'quantity-required', query: '이상한거' } },
//   ]
```

**한 조각이 실패해도 나머지를 버리지 않는다.** 오늘 이 프로젝트에서 가장 비쌌던 버그가
「하나 실패했다고 조용히 전체를 버리는 것」이었다.

## 테스트 요구사항

- **위 표의 모든 행**을 테스트한다
- **한 조각 실패 + 나머지 성공**이 섞인 입력을 반드시 잠근다 —
  실패 조각이 배열에 남아 있고 성공 조각이 정상인지 확인
- 경계값: 조각 0개·1개·10개·11개, 연속 쉼표, 쉼표만, 줄바꿈과 쉼표 혼용
- `TypeError` 는 `assert.throws` 로 잠근다
- **기존 `parseQuickFoodInput` 테스트가 전부 그대로 통과해야 한다.** 그 함수는 안 고친다
- 테스트는 표에서 유도한다. 구현을 읽고 베끼지 않는다
