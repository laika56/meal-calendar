# 로드맵 — 단계 · 모델 · 분담

누가(Claude/Codex/사용자) 무엇을, 어떤 모델로, 어느 정도 힘을 줘서 하는지.
**Codex는 무료 티어다. 쿼터가 유한하므로 "Codex가 할 수 있는 일"이 아니라 "Codex에게 맡기는 게 이득인 일"만 넘긴다.**

## 판단 기준

### Claude 모델 고르는 법

| 이럴 때 | 모델 | 왜 |
|---|---|---|
| 구조 설계, 보안 규칙, 되돌리기 어려운 결정, 원인 불명 버그 | **Opus** | 틀리면 비싼 곳. 여기서 아끼면 나중에 더 쓴다 |
| 명세가 이미 닫힌 구현, UI 마크업, 문서 갱신, 리팩터링 | **Sonnet** | 판단이 아니라 손이 필요한 일 |
| 로그·응답 덤프에서 한 줄 뽑기 같은 단순 추출 | **Haiku** | 이 프로젝트엔 거의 없다 |

세션 시작 시 **내가 먼저 "이건 Sonnet으로 됩니다/Opus 써야 합니다"를 말한다.** 사용자가 묻기 전에.

### Codex에게 넘기는 조건 (4개 전부 만족해야 함)

1. **입출력이 닫혀 있다** — 함수 시그니처와 예시 입출력을 다 적어줄 수 있다
2. **네트워크·부수효과가 없다** — 순수 함수. Firebase·DOM·외부 API를 안 건드린다
3. **테스트로 정답을 확인할 수 있다** — 맞았는지 내가 눈으로 판정하지 않아도 된다
4. **분량이 있다** — 케이스가 많아서 손이 많이 간다. 10줄짜리는 내가 그냥 쓴다

하나라도 안 맞으면 Codex 일이 아니다. **"알아서 잘"이 들어가면 무조건 탈락.**

### Codex 산출물 게이트 (예외 없음)

```
Codex 작성 → 내가 리뷰 (테스트 실행 + 명세 대조) → 사용자 컨펌 → 머지
```

내가 통과시켜도 **사용자 컨펌 전엔 머지 안 한다.** 둘 다 OK여야 들어간다.

## 단계

### Phase 0 — 준비 (블로커)

| 일 | 담당 | 모델/노력 |
|---|---|---|
| 공공데이터포털 식약처 API 키 신청 | **사용자** | — |
| Firebase 프로젝트 생성 + 웹 앱 등록 | **사용자** | — |
| 실기기 iOS에서 PWA 설치·카메라 동작 확인용 최소 페이지 | Claude | Sonnet / 낮음 |

**여기가 안 풀리면 나머지가 전부 가설이다.** 특히 iOS 카메라는 문서로 확정 못 한다.
Codex: 없음.

**끝났다고 말할 수 있는 조건:** 실기기 홈 화면에서 앱으로 열리고, 월 그리드가 보인다.

---

### Phase 2 — 계산 엔진 ★ Codex 1순위

| 일 | 담당 | 모델/노력 |
|---|---|---|
| BMR·TDEE·목적별 매크로 배분 + 테스트 | **Codex** | — |
| 단위 환산 (per100g ↔ 실섭취량, ml↔g, 인분) + 테스트 | **Codex** | — |
| 명세 작성 / 리뷰 | Claude | Opus / 중간 |

**왜 Codex인가:** 조건 4개 전부 만족. 순수 산술, 케이스 많고(성별×활동×목적 = 24조합),
정답을 테스트로 잠글 수 있다.

**넘길 때 반드시 명시할 것:** `SPEC.md`의 공식 표 전문, 경계 케이스(탄수 잔여 음수 → 예외 발생, 0으로 뭉개기 금지), 반올림 규칙.
이걸 안 적으면 Codex가 자기 마음대로 채운다.

### Phase 6 — 룰렛 solver ★ Codex 주력

| 일 | 담당 | 모델/노력 |
|---|---|---|
| 알고리즘 명세 확정 | Claude | Opus / 높음 |
| **solver 구현 + 결정성 테스트 + 다양성 테스트** | **Codex** | — |
| 결과 검증 (오차 ±10%, 재현성) | Claude | Opus / 중간 |

단 **명세를 내가 아주 촘촘히 써야 한다** — 슬롯 비중, 시드 사용법, 후보 부족 시 동작까지.
명세가 허술하면 Codex 쿼터만 태우고 다시 짠다.

## 요약 — Codex에게 줄 것 / 안 줄 것

| ✅ 준다 | ❌ 안 준다 |
|---|---|
| 대사량·매크로 계산 + 테스트 | Firestore 보안 규칙 |
| 단위 환산 | Firebase 연동 코드 |
| 식약처 / OFF 응답 파서 | PWA 셸·서비스워커 |
| 룰렛 solver 알고리즘 | 모든 UI |
| 위 항목들의 테스트 케이스 대량 생성 | 아키텍처 결정 |
| | API 키를 만지는 모든 것 |

**패턴:** 네트워크와 맥락이 없는 순수 로직 = Codex. 나머지 전부 = Claude.
**게이트:** Codex가 낸 것은 내 리뷰 + 사용자 컨펌 둘 다 통과해야 머지된다.
