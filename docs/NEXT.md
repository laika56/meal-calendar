## 막힌 것 (블로커)

| # | 막힌 것 | 푸는 사람 | 왜 이게 먼저인가 |
|---|---|---|---|
| 1 | **Firebase 프로젝트** 생성 + 웹 앱 등록 + Hosting | 사용자 | 데이터 계층 전부가 여기 매달려 있다. **그리고 HTTPS를 준다** |
| 2 | **실기기 iOS 확인** — 홈 화면 설치, standalone 카메라 권한 | 사용자 (페이지는 준비됨) | 문서로 확정 불가. Phase 5 설계가 여기 달려 있다 |
| 3 | 공공데이터포털 **식약처 식품영양성분DB API 키** 신청 | 사용자 | 없으면 식품 검색 전체가 못 움직인다. **승인 대기가 있으니 지금 걸어둔다** |

> **순서 주의 — 2는 1에 매달려 있다.**
> iOS Safari는 `getUserMedia`에 HTTPS를 요구한다. 맥에서 `http://192.168.x.x`로 띄워 폰으로 열면
> 카메라가 막힌다 (`localhost` 예외는 폰 자신의 localhost만 해당).
> **Firebase Hosting이 HTTPS를 주고 나서야 카메라 검증이 성립한다.**
>
> 3은 나머지와 독립이고 승인 대기가 있다 → **제일 먼저 신청만 걸어두고 잊는다.**
