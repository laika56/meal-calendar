# 기능 스펙

원안을 확정형으로 옮긴 것. 뒤집힌 항목의 근거는 `DECISIONS.md`.

## 화면

### 1. 월간 캘린더 (메인)

- 7열 × 5~6행 CSS Grid
- 각 칸: 날짜 + **당일 총 칼로리 숫자** + 목표 대비 상태 색
- 상태 색 기준 (목표 kcal 대비):

| 상태 | 범위 | 의미 |
|---|---|---|
| 미달 | < 90% | 덜 먹음 |
| 달성 | 90~110% | 목표 범위 |
| 초과 | > 110% | 더 먹음 |
| 미기록 | 기록 없음 | 회색 |

  - **색만으로 상태를 구분하지 않는다.** 색각 이상에서 못 읽는다. 숫자·아이콘·테두리를 함께 쓴다.
- 칸 탭 → 해당 날짜 상세

### 2. 일간 상세

- 슬롯 4개: 아침 / 점심 / 저녁 / 간식
- 슬롯마다 항목 추가 — 4가지 입력 경로:
  1. **검색** (식약처 DB)
  2. **바코드** (`zxing-wasm` 카메라 스캔 → Open Food Facts)
  3. **프리셋** 1-Click (자주 먹는 것)
  4. **수동 입력** (DB에 없을 때. 이 비율을 센다 → `DECISIONS.md` 2번의 되돌리는 조건)
- 상단: 오늘 누계 vs 목표 (칼로리 + 탄/단/지 4개 바)
- 당일 체중 입력 (선택)

### 3. 온보딩 / 설정

- 신장, 생년, 성별, 주간 운동 횟수, 목적
- 계산 결과(BMR·TDEE·목표 매크로)를 **보여주고 수동 조정 가능**하게 한다.
  공식은 추정치다. 사용자가 자기 몸을 더 잘 안다.

### 4. 추이

- 체중 · 일별 칼로리 · 매크로 달성률 시계열

## 계산

### BMR — Mifflin-St Jeor

```
남: 10×체중kg + 6.25×신장cm − 5×나이 + 5
여: 10×체중kg + 6.25×신장cm − 5×나이 − 161
```

### TDEE = BMR × 활동계수

| 주간 운동 | 계수 |
|---|---|
| 0회 | 1.2 |
| 1~3회 | 1.375 |
| 4~5회 | 1.55 |
| 6~7회 | 1.725 |

### 목적별 목표

| 목적 | 칼로리 | 단백질 | 지방 | 탄수 |
|---|---|---|---|---|
| 다이어트 | TDEE − 15% | 2.0 g/kg | 총kcal의 25% | 나머지 |
| 린매스업 | TDEE + 5% | 1.8 g/kg | 총kcal의 25% | 나머지 |
| 벌크업 | TDEE + 15% | 1.6 g/kg | 총kcal의 25% | 나머지 |

- 단백질·지방을 먼저 고정하고 **탄수를 잔여로 계산한다.** 순서를 바꾸면 단백질이 깎인다.
- 1g당: 탄수 4kcal, 단백질 4kcal, 지방 9kcal
- 탄수 잔여가 음수면 목표 설정이 모순이다 → **조용히 0으로 만들지 말고 사용자에게 알린다.**

**이 숫자들은 산술이지 의학적 권고가 아니다.** UI에 그렇게 표시한다.

## AI 스마트 룰렛

### 입력
- 잔여 매크로 = 목표 − 현재까지 기록분
- 빈 슬롯 목록
- 기피 식품 (`dislikes`)
- 시드 (재현용)

### 동작
1. 후보 풀 구성 — 기피 제외, 최근 N일 내 먹은 것 가중치 하향(질리지 않게)
2. 빈 슬롯에 잔여 매크로를 배분 (슬롯별 비중: 아침 25 / 점심 35 / 저녁 30 / 간식 10)
3. 슬롯마다 목표 매크로에 가장 가까운 조합을 탐색 — 그리디 + 국소 개선
4. 상위 후보군에서 **시드 셔플로 하나 선택** ← 룰렛의 무작위성은 여기서만 나온다
5. (선택) 선택된 결과를 LLM에 넘겨 설명 문구만 생성

### 규칙
- **같은 시드 + 같은 입력 → 항상 같은 출력.** 테스트로 잠근다
- 잔여 매크로가 음수면 룰렛을 돌리지 않는다. "이미 초과"라고 말한다
- 후보가 부족하면 **억지로 채우지 않는다.** 채운 슬롯 수와 오차를 그대로 보여준다
- 결과는 **제안**이다. 자동 확정하지 않고 사용자가 수락해야 기록된다

### 성공 기준
- 배정 결과의 매크로 합이 잔여 대비 오차 ±10% 이내
- 연속 5회 실행 시 동일 조합이 3회 이상 나오지 않는다 (다양성)
